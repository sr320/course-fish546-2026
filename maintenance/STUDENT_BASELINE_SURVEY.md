# Week 0 Student Baseline Survey

**Purpose:** Identify access barriers, prior experience, expected workload, and unclear course workflows before they affect learning.

**Recommended timing:** Before setup begins, with a short follow-up at the end of Week 1.

**Grading:** Ungraded; responses are used to improve support.

**Privacy:** Review individual access needs privately and report only aggregate course findings.

## Before setup

1. Which required accounts or services can you currently access?
   - GitHub account
   - FISH 546 GitHub organization
   - Course Slack
   - UW VPN/Husky OnNet
   - Raven RStudio Server
   - Hyak/Klone by SSH or OnDemand
   - I am unsure how to test one or more of these

2. Which operating system will you use most often?
   - macOS
   - Windows
   - Linux
   - Other or unsure

3. Rate your current confidence from 1 (not yet confident) to 5 (very confident):
   - Navigating files in a terminal
   - Using Git commits, branches, and pushes
   - Working with GitHub issues and pull requests
   - Writing or rendering a Quarto document
   - Using R or RStudio
   - Working on a shared server
   - Submitting or monitoring an HPC batch job
   - Interpreting bioinformatics quality-control output

4. Approximately how many hours do you expect to have available for course work outside class each week?

5. What is the most important technical or access concern you have before the course begins?

6. Do you need the instructor to contact you privately about access, equipment, scheduling, or another barrier?
   - No
   - Yes — provide a private contact route rather than asking for sensitive details in this survey

## End of Week 1 follow-up

7. How long did each setup tutorial take?
   - Tutorial 1: Your computer
   - Tutorial 2: Raven
   - Tutorial 3: Hyak/Klone

8. Which setup steps required help or remain incomplete?

9. For each activity, select the destination you would use:
   - Submit a weekly question set
   - Submit a weekly class assignment
   - Record weekly research-project progress
   - Ask for help with a specific error
   - Discuss an open-ended biological or methodological question

10. Rate from 1 (unclear) to 5 (very clear):
    - What is due each week
    - Where each type of work is submitted
    - What evidence belongs in a progress issue
    - Where to ask for help
    - How weekly work contributes to the final compendium

11. What single change would have made setup or Week 1 easier?

12. Is there anything in the course site that currently contradicts another instruction? If so, include both locations.
